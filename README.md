# Keylogger
A keylogger made in python. 
Only Works for WINDOWS,LINUX BASED SYSTEMS!!!!
Functionalities:
    1)Uploads the Encryption key to dropbox cloud server
    2)Deletes the key file from victim pc
    3)Read all the letters victim types and save them into a file.
    4)Encrypts the whole file
    5)If user clicks on anything captures a screenshot uploads it to dropbox cloud server and deletes it.
    6)Once user ends program or switches off pc every file is uploaded on the cloud server and the keylogger file deletes itself and all the files it created leaving no trace
    
Things you need to specify in the file:
    1)Your File name
    2)Your dropbox access token
    Thats it.
